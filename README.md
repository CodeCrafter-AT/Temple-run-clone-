# Temple Run Clone

A lightweight endless runner inspired by Temple Run, built with plain HTML, CSS, and JavaScript.

## How to run

Open `index.html` in a browser.

## Controls

- Move left/right: Left Arrow / Right Arrow or A / D
- Jump: Up Arrow / W / Space
- Restart: Start Run button or Enter while game over

## Notes

This is a simple browser game prototype designed to work without any dependencies or build tools.
